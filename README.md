# Stream Auto Cutter

Удобное приложение для автоматической нарезки видео (например, записей стримов), наложения логотипов, добавления интро/аутро и конвертации в нужный формат.

## 🚀 Как запустить (Инструкция для новичков)

Даже если вы не программист, запустить программу очень просто! Следуйте шагам ниже:

### Шаг 1: Установка Python
1. Скачайте Python с официального сайта: [python.org/downloads](https://www.python.org/downloads/)
2. Запустите установщик.
3. **ОЧЕНЬ ВАЖНО:** При установке в самом начале обязательно поставьте галочку **"Add Python to PATH"** (или "Add python.exe to PATH").
4. Нажмите "Install Now" и дождитесь окончания установки.

### Шаг 2: Установка FFmpeg
Эта программа использует `FFmpeg` для обработки видео. Его также нужно установить.
1. Самый простой способ для Windows - скачать готовую сборку (например, от gyan.dev или BtbN).
   - Инструкция по установке FFmpeg на Windows (текст+картинки): [как установить FFmpeg](https://www.hostinger.com/tutorials/how-to-install-ffmpeg#How_to_Install_FFmpeg_on_Windows) (или найдите видео на YouTube "Как установить FFmpeg на Windows").
2. **ОЧЕНЬ ВАЖНО:** Убедитесь, что вы добавили папку `bin` от FFmpeg в "Переменные среды" (System PATH), чтобы ваш компьютер знал, где находится эта программа.
3. Чтобы проверить, что все работает, откройте командную строку (cmd) и напишите `ffmpeg`. Если появится много текста с версией программы — всё отлично!

### Шаг 3: Скачивание программы
1. Скачайте этот проект себе на компьютер (зеленая кнопка `Code` -> `Download ZIP`).
2. Распакуйте архив в удобную папку.

### Шаг 4: Установка зависимостей и запуск
1. Откройте папку с распакованной программой.
2. В адресной строке проводника (там, где написан путь к папке) сотрите всё, напишите `cmd` и нажмите Enter. Откроется черное окно командной строки прямо в этой папке.
3. Напишите команду для установки нужных библиотек (нужен интернет) и нажмите Enter:
   ```cmd
   pip install -r requirements.txt
   ```
   *Дождитесь, пока всё скачается и установится.*
4. Теперь запускаем саму программу! Напишите команду:
   ```cmd
   python main.py
   ```
5. Должно открыться окно **Stream Auto Cutter**. В следующий раз для запуска вам нужно будет выполнить только пункт 4!

## 💡 Создание быстрого ярлыка для запуска (для Windows)
Чтобы каждый раз не открывать черное окно командной строки, вы можете создать файл запуска:
1. В папке с программой создайте обычный текстовый документ.
2. Впишите туда две строчки:
   ```bat
   pip install -r requirements.txt
   python main.py
   ```
3. Сохраните файл и переименуйте его, например, в `start.bat` (обязательно измените расширение `.txt` на `.bat`).
4. Теперь программа будет запускаться двойным кликом по этому файлу!

---

**Если что-то не работает:**
Убедитесь, что вы не забыли поставить галочку **"Add to PATH"** при установке Python, и что правильно настроили **FFmpeg**. Это самые частые причины проблем!
